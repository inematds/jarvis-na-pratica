Swappable brain: change your assistant’s AI and it still asks before deleting

When you build an AI assistant, you can get stuck with one company. If the price goes up or you hit a limit, switching feels like starting over. How it works

The brain thinks. The rest belongs to Jarvis.

Think of a company: the brain is the employee you hire, and Jarvis is the office, with the rules on the wall. Replacing the employee doesn’t change the rules.

You make a request→Jarvis adds memory and rules→the brain decides→the safeguard checks→it runs in a closed box→response

🧠 The brain only decides

It receives the conversation and says, “I want to check the disk” or “I want to delete the logs folder.” It doesn’t touch anything on the computer.

🔒 The safeguard belongs to Jarvis

It works like a gatekeeper for commands on your computer: read-only requests (check disk space, list folders) go through; every other request waits for your OK; and anything irreversible (shutting down or restarting the computer, deleting everything, acting as an administrator) is blocked, even with your OK. Creating or editing a file you asked for always stays inside the work folder.

📦 The closed box

Approved commands run in a box without internet access, locked to the work folder (a program called Docker creates this box). If something goes wrong, it stays inside.

📒 Memory and log

What you ask Jarvis to remember stays with Jarvis, not the AI. Every command, approved or not, is recorded in a log.

⚠️ What this does not promise

It doesn’t make any AI smarter: a weak brain can still get the answer wrong. What it guarantees is protection: even if the AI makes a mistake, it can’t delete or restart anything without going through the safeguard. We ran one test with each brain on a server. Times can vary from day to day.

You don’t need to install anything by hand. The AI reads the project, checks your computer, and tells you which brain you can already use.

Common questions

Before you start

Do I need to know how to code?

No. Paste the request, read the plan the AI shows you, and say yes or no. The AI installs it.

How much does it cost?

The project is free. With Claude Code or Codex, you use the subscription you already have. With OpenRouter, you pay only for what you use, in cents.

Do I need all three brains?

No. One is enough. All three are there so you can switch whenever you want.

Does it work on Windows or Mac?

We tested it on a Linux server. In step 1 of “How to start,” your AI checks your computer and tells you if it will work.

Can the AI delete something without me seeing?

Not this way. The brain doesn’t run commands; Jarvis does, after the safeguard check. Every command that does more than read waits for your OK. Anything irreversible is blocked, and files it creates stay in the work folder.

Does it work through Telegram?

INTELECTO has a Telegram channel. For this demo, we used the computer’s command screen (the terminal) so we could measure all three the same way.

What if I already use INTELECTO?

This project doesn’t change your INTELECTO. It only adds the three brains on top.
